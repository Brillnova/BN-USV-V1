# V1 reference hull files

`stl/` contains the V1 hull mesh files used for the reference prototype.

`assembly/BN_USV_V1.FCStd` is a FreeCAD project composed from those STL meshes. It is included for reference and mesh arrangement; it is not the original parametric CAD source.

See [Reference hull files](../docs/REFERENCE_HULL_FILES.md) for the CC BY-NC-SA 4.0 terms, scope and attribution requirements. V1 requires substantial post-processing, bonding and waterproofing and is not a turnkey DIY kit.
