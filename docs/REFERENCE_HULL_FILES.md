# V1 reference hull files

This release includes the V1 reference hull mesh files in [`hardware/stl`](../hardware/stl), plus the [`BN_USV_V1.FCStd`](../hardware/assembly/BN_USV_V1.FCStd) FreeCAD assembly and a preview image in [`hardware/assembly`](../hardware/assembly).

The FreeCAD project is an assembly of the released STL meshes. It is provided for viewing and arranging those meshes; it is not the original parametric CAD source.
