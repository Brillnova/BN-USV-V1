# Assembly notes

V1 is an experimental reference prototype. Its hull requires substantial post-processing, bonding and waterproofing. The project does not provide individual build support or guarantees of assembly success, seaworthiness or performance.

Use only a configuration appropriate for your operating environment. Inspect every waterproofing point and confirm neutral propulsion output, manual override and failsafe behavior before testing. Conduct initial tests in a controlled environment and follow applicable local rules.

The BOM for a future release will list only components tested by Brillnova. Substitute parts are not validated.
